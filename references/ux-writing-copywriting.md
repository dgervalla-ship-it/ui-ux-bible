<a id="section-1"></a>
## Objectif

Le UX Writing consiste à rédiger les textes présents dans une interface :

* boutons ;
* menus ;
* formulaires ;
* messages d’erreur ;
* notifications ;
* onboarding ;
* confirmations.

Le Copywriting, lui, vise à convaincre et à convertir.

Dans un bon produit, ces deux disciplines travaillent ensemble :

* Le UX Writing facilite l’utilisation.
* Le Copywriting donne envie d’agir.

<a id="section-2"></a>
## Les principes fondamentaux

Chaque texte doit être :

* utile ;
* simple ;
* précis ;
* humain ;
* orienté utilisateur.

Chaque mot inutile peut augmenter la charge cognitive.

<a id="section-3"></a>
## La règle d’or

### Écrire comme une personne parle

### Mauvais exemple

Une erreur est survenue durant l’exécution de votre requête.

### Bon exemple

Impossible d’enregistrer vos modifications. Réessayez.

Le deuxième texte est :

* plus humain ;
* plus compréhensible ;
* plus rassurant.

<a id="section-4"></a>
## L’utilisateur est le héros

Ne parle pas de ton entreprise.

Parle du résultat obtenu par l’utilisateur.

❌

Notre technologie révolutionnaire…

✔

Simplifiez vos tâches quotidiennes.

<a id="section-5"></a>
## Utiliser des verbes

Les verbes rendent une interface plus claire.

✔

Créer

Télécharger

Modifier

Supprimer

Partager

Exporter

Importer

Évite les noms seuls.

❌

Validation

Gestion

Configuration

<a id="section-6"></a>
## Une idée par phrase

Chaque phrase répond à une seule question.

Évite :

Votre compte sera créé afin que vous puissiez accéder à tous les services proposés par notre plateforme.

Préfère :

Créez votre compte.

Accédez aux services dont vous avez besoin.

<a id="section-7"></a>
## Les titres

Un titre doit répondre immédiatement à :

Pourquoi suis-je ici ?

Exemple :

✔

Créer un projet

Modifier votre profil

Paiement

Historique des commandes

### À éviter

Informations

Gestion

Accueil

Divers

<a id="section-8"></a>
## Les sous-titres

Ils répondent à :

Pourquoi cette page existe ?

Exemple :

Ajoutez les informations nécessaires pour créer votre premier projet.

<a id="section-9"></a>
## Les boutons

Le texte d’un bouton décrit l’action.

### À privilégier

✔

Créer un compte

Télécharger le PDF

Ajouter au panier

Confirmer le paiement

### À éviter

OK

Continuer

Suivant

Valider

Ces mots n’ont aucun contexte.

<a id="section-10"></a>
## Les messages d’erreur

Chaque message doit répondre à trois questions.

Que s’est-il passé ?

Pourquoi ?

Que faire ?

### Mauvais exemple

Erreur 504

### Bon exemple

Impossible de charger vos projets.
Vérifiez votre connexion puis réessayez.

<a id="section-11"></a>
## Les confirmations

Une confirmation rassure.

Exemple :

✔

Votre profil a été mis à jour.

✔

Votre facture a été envoyée.

✔

Le projet a été créé.

Une confirmation ne doit jamais laisser de doute.

<a id="section-12"></a>
## Les notifications

Une notification répond à une seule information.

Elle est :

* courte ;
* utile ;
* actionnable.

Exemple :

✔

Votre paiement a été accepté.

Voir la facture.

<a id="section-13"></a>
## Les textes d’aide

Les textes d’aide doivent apparaître avant les erreurs.

Exemple :

Mot de passe
Minimum 12 caractères.

Plutôt que :

Erreur.

Mot de passe trop court.

<a id="section-14"></a>
## Les placeholders

Le placeholder montre un exemple.

Jamais une instruction.

✔

Exemple :

nom@entreprise.com

❌

Veuillez saisir votre adresse e-mail professionnelle.

<a id="section-15"></a>
## Les liens

Le texte d’un lien doit décrire sa destination.

✔

Voir les détails

Télécharger le contrat

Lire la documentation

❌

Cliquez ici

Lire

Voir

<a id="section-16"></a>
## Les CTA

Le Call To Action doit répondre à :

Que vais-je obtenir ?

Exemple :

✔

Créer gratuitement mon compte

Recevoir le guide

Commencer l’essai gratuit

Réserver une démonstration

Un bénéfice clair peut faciliter la décision ; vérifier son effet sur le taux de clic par un test approprié.

<a id="section-17"></a>
## Les émotions

Une bonne interface reste professionnelle.

Évite les formulations excessives.

❌

INCROYABLE !!

MEILLEURE OFFRE DU SIÈCLE !!

Préfère une communication calme et crédible.

<a id="section-18"></a>
## Les nombres

Les chiffres renforcent la crédibilité.

Exemple :

✔

Économisez jusqu’à [durée vérifiée] par semaine.

✔

Plus de [nombre vérifié] utilisateurs.

Les chiffres doivent être précis et vérifiables.

<a id="section-19"></a>
## Les FAQ

Une FAQ répond aux objections.

Chaque réponse reste courte.

Une FAQ n’est pas un manuel.

<a id="section-20"></a>
## Le ton

Le ton dépend du produit.

### Banque

Calme.

Précis.

Professionnel.

### Réseau social

Simple.

Amical.

Rapide.

### SaaS B2B

Professionnel.

Pédagogique.

Efficace.

L’important est de conserver le même ton dans toute l’interface.

<a id="section-21"></a>
## Les erreurs fréquentes

❌ Jargon technique.

❌ Acronymes incompréhensibles.

❌ Boutons vagues.

❌ Paragraphes trop longs.

❌ Humour pendant une erreur critique.

❌ Plusieurs styles d’écriture.

❌ Messages culpabilisants.

<a id="section-22"></a>
## Les microcopies

Les microcopies sont les petits textes.

Exemple :

* texte d’aide ;
* tooltip ;
* placeholder ;
* erreur ;
* confirmation ;
* compteur.

Ces petits textes influencent énormément l’expérience utilisateur.

<a id="section-23"></a>
## Cas pratique

### Mauvaise version

Erreur
Veuillez réessayer.

L’utilisateur ne sait pas :

* ce qui s’est passé ;
* pourquoi ;
* comment résoudre le problème.

### Bonne version

Impossible d'envoyer votre message.
Votre connexion Internet semble interrompue.
Reconnectez-vous puis réessayez.

Le problème est clair.

La solution aussi.

<a id="section-24"></a>
## Checklist du chapitre

Avant de publier une interface :

* ☐ Chaque bouton commence par un verbe.
* ☐ Les titres expliquent immédiatement la page.
* ☐ Les messages d’erreur proposent une solution.
* ☐ Les confirmations rassurent l’utilisateur.
* ☐ Les textes utilisent le vocabulaire des utilisateurs.
* ☐ Les phrases sont courtes.
* ☐ Les liens décrivent leur destination.
* ☐ Les CTA mettent en avant le bénéfice.
* ☐ Les chiffres utilisés sont précis et crédibles.
* ☐ Le ton reste cohérent sur tout le produit.

<a id="section-25"></a>
## Ce qu’il faut retenir

Les mots font partie de l’interface.

Un bon texte peut réduire les erreurs et rassurer l’utilisateur ; mesurer séparément son effet sur la conversion.

L’objectif n’est pas d’écrire davantage.

L’objectif est d’écrire exactement ce que l’utilisateur a besoin de lire au moment où il en a besoin.
