Chapitre 20 — La Psychologie Cognitive appliquée à l’UX

Une bonne interface ne fonctionne pas parce qu’elle est belle. Elle fonctionne parce qu’elle respecte le fonctionnement naturel du cerveau humain.

⸻

Objectif

Toutes les décisions de design doivent être basées sur la psychologie humaine.

Les utilisateurs :

* ne lisent pas tout ;
* ne mémorisent pas grand-chose ;
* prennent des raccourcis ;
* cherchent le chemin le plus simple ;
* évitent les efforts inutiles.

Concevoir une interface revient donc à concevoir pour le cerveau humain.

⸻

Les limites du cerveau

Le cerveau possède plusieurs contraintes.

Les ignorer produit une mauvaise expérience.

Les respecter rend l’interface intuitive.

⸻

Charge cognitive

Chaque décision demande de l’énergie mentale.

Lorsque cette énergie diminue :

* les erreurs augmentent ;
* la fatigue apparaît ;
* les abandons augmentent.

L’objectif du designer est donc de réduire cette charge.

⸻

Réduire la charge cognitive

Pour cela :

* limiter les choix ;
* supprimer les informations inutiles ;
* regrouper les éléments liés ;
* utiliser les conventions existantes.

Chaque élément supprimé améliore souvent l’expérience.

⸻

La mémoire de travail

La mémoire humaine est limitée.

L’utilisateur ne peut conserver qu’un petit nombre d’informations en tête en même temps.

Conséquences :

Ne jamais demander :

* de retenir une information affichée sur une autre page ;
* de comparer plusieurs écrans ;
* de mémoriser une procédure complexe.

L’interface doit afficher ce dont l’utilisateur a besoin, au moment où il en a besoin.

⸻

Le principe de reconnaissance

Les utilisateurs préfèrent reconnaître plutôt que mémoriser.

Exemple :

✔ Liste des projets récents.

✔ Historique.

✔ Suggestions.

✔ Icônes familières.

Ces éléments réduisent l’effort mental.

⸻

La Loi de Hick

Plus il existe de choix,

plus la décision prend du temps.

Exemple :

Deux boutons.

↓

Décision rapide.

⸻

Douze boutons.

↓

Analyse.

↓

Hésitation.

↓

Abandon possible.

⸻

Application

Limiter :

* les menus ;
* les actions ;
* les paramètres visibles.

Afficher les options avancées uniquement lorsque c’est nécessaire.

⸻

La Loi de Fitts

Plus une cible est :

* grande ;
* proche ;

plus elle est rapide à atteindre.

Conséquences :

Les CTA principaux doivent être :

* grands ;
* faciles à cliquer ;
* placés près de la zone d’attention.

Les petites zones interactives augmentent les erreurs.

⸻

La Loi de Miller

Le cerveau regroupe naturellement les informations.

Créer des groupes facilite la compréhension.

Exemple :

Informations personnelles

↓

Adresse

↓

Paiement

est plus simple que :

Nom

Carte bancaire

Téléphone

Ville

Email

⸻

Les principes de Gestalt

Notre cerveau organise automatiquement les éléments.

Les principaux principes utiles en UI sont :

Proximité

Les éléments proches semblent appartenir au même groupe.

⸻

Similarité

Deux éléments ayant la même apparence semblent avoir la même fonction.

Un bouton bleu est attendu comme identique à un autre bouton bleu.

⸻

Continuité

Le regard suit naturellement les alignements.

Des colonnes bien alignées accélèrent la lecture.

⸻

Figure / Fond

Le cerveau distingue automatiquement :

* ce qui est important ;
* ce qui est secondaire.

Le contraste joue un rôle essentiel.

⸻

Fermeture

Le cerveau complète naturellement les formes incomplètes.

C’est pourquoi une interface minimaliste reste souvent compréhensible.

⸻

Le biais de confirmation

Les utilisateurs cherchent des informations qui confirment leurs attentes.

Une interface qui respecte les conventions réduit donc les incompréhensions.

⸻

Le coût de changement

Changer une habitude demande un effort.

Exemple :

Déplacer le menu principal sans raison oblige les utilisateurs à réapprendre.

Le coût est souvent supérieur au bénéfice.

⸻

L’effet de position sérielle

Les utilisateurs retiennent davantage :

* le premier élément ;
* le dernier élément.

Conséquences :

Les actions importantes apparaissent :

* au début ;
* ou à la fin d’une liste.

Les actions secondaires sont placées au milieu.

⸻

L’effet Von Restorff

Un élément différent attire immédiatement l’attention.

Exemple :

Tous les boutons sont gris.

↓

Un seul est bleu.

↓

Le regard va immédiatement vers lui.

Cette règle explique pourquoi un CTA principal doit être unique.

⸻

L’effet de progression

Les utilisateurs terminent plus facilement une tâche lorsqu’ils voient leur progression.

Exemple :

Étape 2 sur 5.

Une barre de progression réduit les abandons.

⸻

L’effet Zeigarnik

Le cerveau retient les tâches inachevées.

Les interfaces peuvent exploiter cet effet.

Exemple :

Votre profil est complété à 80 %.

↓

L’utilisateur souhaite naturellement terminer.

⸻

La récompense immédiate

Les utilisateurs apprécient un retour rapide.

Exemple :

Animation.

Notification.

Message de réussite.

Ces retours renforcent la sensation de contrôle.

⸻

La peur de perdre

Les utilisateurs sont généralement plus sensibles à une perte qu’à un gain équivalent.

Exemple :

Votre essai expire dans 2 jours.

est souvent plus mobilisateur que :

Continuez à profiter de toutes les fonctionnalités.

À utiliser avec mesure et sans manipulation.

⸻

La confiance

La confiance se construit grâce à :

* une interface cohérente ;
* des messages clairs ;
* des performances stables ;
* des informations transparentes ;
* des erreurs bien expliquées.

La confiance est l’un des facteurs les plus importants de la fidélisation.

⸻

Les erreurs fréquentes

❌ Trop d’informations sur un écran.

❌ Plus de 10 actions de même importance.

❌ Interface différente à chaque page.

❌ Absence de feedback.

❌ Changement des conventions.

❌ Informations demandant à être mémorisées.

❌ Trop d’animations.

⸻

Cas pratique

Imaginons une application bancaire.

Mauvaise conception

* 18 options sur la page d’accueil.
* Plusieurs boutons de même importance.
* Aucun indicateur de progression lors d’un virement.
* Confirmation discrète après validation.

L’utilisateur hésite et manque de repères.

Bonne conception

* 4 actions principales clairement visibles.
* Un seul bouton primaire.
* Un parcours guidé étape par étape.
* Une barre de progression.
* Une confirmation explicite avec les détails du virement.

Le parcours demande moins d’effort mental et inspire davantage confiance.

⸻

Checklist du chapitre

Avant de publier une interface :

* ☐ Les choix proposés sont limités au nécessaire.
* ☐ Les informations sont regroupées logiquement.
* ☐ Les conventions connues sont respectées.
* ☐ Les actions principales sont clairement mises en avant.
* ☐ L’utilisateur reçoit un retour immédiat après chaque action.
* ☐ La progression est visible dans les parcours longs.
* ☐ Les éléments similaires ont un comportement identique.
* ☐ Les informations importantes apparaissent au bon moment.
* ☐ L’interface minimise les efforts de mémorisation.
* ☐ Les décisions de design s’appuient sur le fonctionnement du cerveau humain.

⸻

Ce qu’il faut retenir

Les meilleurs designers ne conçoivent pas pour eux-mêmes.

Ils conçoivent pour les limites et les capacités du cerveau humain.

Une interface réussie ne demande pas à l’utilisateur de devenir plus intelligent.

Elle s’adapte à sa manière naturelle de percevoir, comprendre, décider et agir.
