## Objectif
La typographie est l’un des piliers de l’expérience utilisateur.

Elle ne consiste pas uniquement à choisir une belle police.

Une bonne typographie permet de :

* améliorer la lisibilité ;
* créer une hiérarchie visuelle ;
* guider le regard ;
* renforcer l’identité du produit ;
* réduire la fatigue visuelle.

Le texte représente souvent plus de 80 % du contenu d’une interface. Il mérite donc une attention particulière.

La typographie est un système

Une erreur fréquente consiste à choisir des tailles de texte au hasard.

Une interface professionnelle repose sur un système typographique cohérent.

Ce système définit :

* les tailles ;
* les graisses ;
* les espacements ;
* les longueurs de ligne ;
* les hauteurs de ligne.

Les qualités d’une bonne police

Une police destinée aux interfaces doit être :

* lisible sur écran ;
* régulière ;
* neutre ;
* disponible sur plusieurs systèmes ;
* performante au chargement.

Elle doit rester confortable aussi bien à 14 px qu’à 48 px.

Combien de polices utiliser ?

Une seule police est suffisante dans la majorité des projets.

Deux familles peuvent être utilisées lorsque les rôles sont clairement distincts.

Par exemple :

* une police pour les titres ;
* une police pour le texte courant.

Au-delà, la cohérence devient plus difficile à maintenir.

L’échelle typographique

Chaque niveau d’information possède une taille spécifique.

Exemple d’échelle :

Élément	Taille
H1	48 px
H2	36 px
H3	30 px
H4	24 px
H5	20 px
H6	18 px
Texte principal	16 px
Texte secondaire	14 px
Légende	12 px

L’objectif n’est pas de multiplier les tailles, mais de créer une hiérarchie claire.

Le texte courant

Le texte principal doit rester confortable à lire.

Dans la plupart des interfaces modernes :

* 16 px constitue une excellente base.

Descendre à 12 ou 13 px pour le contenu principal réduit fortement le confort de lecture.

La hauteur de ligne

Le texte a besoin d’espace pour respirer.

Une hauteur de ligne trop faible donne une impression d’écrasement.

Une hauteur excessive casse la continuité de lecture.

Une règle simple consiste à utiliser une hauteur comprise entre 1,4 et 1,7 fois la taille du texte.

Exemple :

* texte : 16 px ;
* hauteur de ligne : 24 px.

La longueur des lignes

Des lignes trop longues fatiguent les yeux.

Des lignes trop courtes ralentissent la lecture.

Pour un paragraphe, une longueur comprise entre 50 et 80 caractères par ligne offre généralement un bon confort de lecture.

L’alignement

Pour les langues qui se lisent de gauche à droite :

Le texte est généralement aligné à gauche.

Évite les paragraphes justifiés sur le Web : ils créent souvent des espacements irréguliers qui nuisent à la lecture.

Le texte centré est à réserver aux éléments courts (titres, slogans, cartes).

Les graisses

Chaque graisse doit avoir une fonction.

Exemple :

Graisse	Utilisation
Regular	Texte courant
Medium	Libellés importants
Semibold	Sous-titres
Bold	Titres et mise en avant

Évite d’utiliser du gras partout.

Si tout est en gras, plus rien ne ressort.

Les couleurs du texte

La couleur du texte participe à la hiérarchie.

Une interface peut distinguer :

* le titre principal ;
* le texte courant ;
* les informations secondaires ;
* les textes désactivés.

Utilise différents niveaux de gris plutôt que plusieurs couleurs.

Les espacements verticaux

Les titres doivent respirer.

Exemple :

Titre
24 px
Paragraphe
32 px
Titre suivant

Des espacements cohérents rendent la lecture plus fluide.

Les paragraphes

Un bon paragraphe :

* développe une seule idée ;
* reste relativement court ;
* est séparé des autres par un espace suffisant.

Sur écran, plusieurs petits paragraphes sont souvent préférables à un seul bloc très dense.

Les listes

Les listes facilitent le balayage visuel.

Privilégie-les lorsque tu présentes :

* des avantages ;
* des fonctionnalités ;
* des étapes ;
* des recommandations.

Chaque élément doit commencer par une formulation homogène.

Les titres

Un titre doit :

* être court ;
* annoncer clairement le contenu ;
* être immédiatement identifiable.

Évite les titres vagues.

Préfère :

Créer un compte

plutôt que :

Informations générales

Les majuscules

Les mots entièrement en majuscules ralentissent la lecture.

Réserve-les aux cas particuliers :

* petits labels ;
* badges ;
* catégories.

Évite les paragraphes en capitales.

Les italiques

Les italiques sont utiles pour :

* des citations ;
* des mots étrangers ;
* certaines mises en évidence.

Ils sont moins lisibles que le texte normal lorsqu’ils sont utilisés en grande quantité.

Les nombres

Les nombres doivent être faciles à comparer.

Aligne-les correctement dans les tableaux.

Utilise toujours le même format.

Exemple :

* 1 250 €
* 15 800 €
* 240 000 €

La cohérence facilite la lecture.

Les formulaires

Dans un formulaire :

Le label précède le champ.

Le texte d’aide apparaît sous le champ.

Le message d’erreur est clairement différencié.

Le placeholder ne remplace jamais un label.

Les tableaux

Dans un tableau :

* les en-têtes sont plus visibles ;
* les données importantes ressortent ;
* les colonnes sont correctement alignées.

Une bonne typographie améliore considérablement la compréhension.

Les erreurs fréquentes

❌ Trop de tailles de police.

❌ Trop de graisses différentes.

❌ Texte gris clair sur fond blanc.

❌ Paragraphes trop longs.

❌ Lignes de plus de 100 caractères.

❌ Texte centré sur de longues sections.

❌ Utilisation excessive des majuscules.

❌ Placeholder utilisé comme unique indication.
<a id="section-2"></a>
## Cas pratique
Prenons une page d’article.

Une mauvaise typographie utiliserait :

* quatre familles de polices ;
* sept tailles différentes sans logique ;
* des paragraphes très longs ;
* un faible contraste ;
* des titres peu distincts.

Une meilleure approche utiliserait :

* une seule famille de police ;
* une échelle typographique stable ;
* un texte principal à 16 px ;
* des paragraphes courts ;
* des titres bien espacés ;
* un contraste élevé entre le texte et le fond.

Le contenu devient immédiatement plus agréable à lire.
<a id="section-3"></a>
## Checklist du chapitre
Avant de valider une interface :

* ☐ Une seule famille de police est utilisée (ou deux au maximum avec des rôles distincts).
* ☐ Les tailles suivent une échelle cohérente.
* ☐ Les hauteurs de ligne assurent une lecture confortable.
* ☐ Les lignes ne sont ni trop longues ni trop courtes.
* ☐ Les titres sont clairement hiérarchisés.
* ☐ Les couleurs du texte distinguent les niveaux d’information.
* ☐ Les paragraphes sont aérés.
* ☐ Les listes sont utilisées lorsque cela améliore la compréhension.
* ☐ Les labels des formulaires restent visibles.
* ☐ Les nombres sont présentés de manière cohérente.

<a id="section-4"></a>
## Ce qu’il faut retenir
Une bonne typographie ne cherche pas à attirer l’attention.

Elle rend la lecture naturelle.

Lorsque les utilisateurs oublient la police et se concentrent uniquement sur le contenu, la typographie a parfaitement rempli son rôle.
