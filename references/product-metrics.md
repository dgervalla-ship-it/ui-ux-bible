<a id="section-1"></a>
## Objectif
Une bonne expérience utilisateur ne se juge pas uniquement par son apparence.

Elle se mesure.

Les métriques UX permettent de répondre à des questions essentielles :

* Les utilisateurs comprennent-ils le produit ?
* Atteignent-ils leurs objectifs ?
* Reviennent-ils ?
* Où abandonnent-ils ?
* Quelles fonctionnalités créent de la valeur ?

Le rôle des métriques est d’aider les équipes à prendre des décisions basées sur des faits.

UX ≠ UI

Une belle interface peut avoir de mauvaises performances.

À l’inverse :

Une interface simple peut offrir une excellente expérience.

Les métriques permettent de distinguer :

* ce qui est esthétique ;
* ce qui fonctionne réellement.

Les trois niveaux de métriques

Toutes les métriques peuvent être regroupées en trois catégories.

Business
↓
Produit
↓
UX

Les trois doivent évoluer ensemble.

Les métriques Business

Elles répondent à :

L’entreprise atteint-elle ses objectifs ?

Exemples :

* chiffre d’affaires ;
* panier moyen ;
* coût d’acquisition ;
* marge ;
* taux de conversion.

Les métriques Produit

Elles répondent à :

Le produit est-il utilisé ?

Exemples :

* utilisateurs actifs ;
* fréquence d’utilisation ;
* activation ;
* rétention ;
* engagement.

Les métriques UX

Elles répondent à :

L’expérience est-elle bonne ?

Exemples :

* temps nécessaire pour terminer une tâche ;
* taux d’erreur ;
* abandon ;
* satisfaction ;
* facilité d’utilisation.

Le Funnel (Tunnel)

Tous les produits possèdent un parcours.

Exemple :

Visite
↓
Inscription
↓
Activation
↓
Utilisation
↓
Abonnement
↓
Fidélisation

À chaque étape :

des utilisateurs quittent le parcours.

Le but est de comprendre pourquoi.

Le taux de conversion

Le taux de conversion mesure :

Nombre de personnes ayant réalisé l’action attendue.

Exemple :

100 visiteurs.

↓

25 inscriptions.

↓

Conversion = 25 %.

Une amélioration UX peut augmenter cette valeur sans modifier le marketing.

L’Activation

L’activation représente le moment où un nouvel utilisateur découvre réellement la valeur du produit.

Exemple :

Un logiciel de gestion de projet.

Créer un compte ne suffit pas.

L’activation peut être :

Créer son premier projet.

Inviter une équipe.

Créer sa première tâche.

Le produit doit conduire rapidement l’utilisateur vers cette étape.

La rétention

La rétention mesure :

Les utilisateurs reviennent-ils ?

Exemple :

Jour 1

↓

Jour 7

↓

Jour 30

↓

Jour 90

Un excellent onboarding ne suffit pas.

Le produit doit conserver son intérêt.

Le churn

Le churn représente :

Les utilisateurs qui partent.

Analyser :

Pourquoi ?

Quand ?

Après quelle action ?

Le churn est souvent un excellent indicateur des problèmes UX.

Le temps de tâche

Mesurer :

Combien de temps faut-il pour :

* créer un compte ;
* envoyer une facture ;
* terminer un paiement.

Un temps anormalement long révèle souvent une interface complexe.

Le taux d’erreur

Mesurer :

* erreurs de formulaire ;
* clics inutiles ;
* retours en arrière ;
* annulations.

Une augmentation des erreurs indique généralement un problème d’utilisabilité.

Les clics

Observer :

Combien de clics sont nécessaires ?

Exemple :

Créer une facture.

Interface A

↓

12 clics.

Interface B

↓

5 clics.

La seconde est probablement plus efficace.

Le taux d’abandon

Les utilisateurs quittent-ils :

* un formulaire ?
* un paiement ?
* une recherche ?

Identifier précisément :

À quelle étape ?

Puis chercher pourquoi.

La satisfaction

Les données quantitatives ne suffisent pas.

Il faut également mesurer :

La perception.

Quelques méthodes :

* questionnaire de satisfaction ;
* entretiens ;
* commentaires.

Le Net Promoter Score (NPS)

Le NPS mesure :

La probabilité qu’un utilisateur recommande le produit.

Il ne mesure pas directement la qualité UX.

Il donne une indication sur la satisfaction globale.

Il doit être interprété avec les autres métriques.

Le Customer Satisfaction Score (CSAT)

Le CSAT mesure la satisfaction après une interaction précise.

Exemple :

Après un achat.

Après une conversation avec le support.

Après une réservation.

Il est utile pour identifier les étapes problématiques du parcours.

Les métriques d’engagement

Observer :

* fréquence d’utilisation ;
* durée des sessions ;
* fonctionnalités utilisées ;
* actions récurrentes.

Une fonctionnalité peu utilisée mérite parfois d’être simplifiée… ou supprimée.

Les dashboards UX

Toutes les équipes devraient disposer d’un tableau de bord regroupant les indicateurs essentiels.

Exemple :

Activation
82 %
↓
Conversion
31 %
↓
Temps moyen
2 min 40
↓
Taux d'erreur
3 %
↓
Rétention 30 jours
61 %

L’objectif n’est pas de suivre des dizaines d’indicateurs, mais de se concentrer sur ceux qui influencent réellement les décisions.

Les erreurs fréquentes

❌ Mesurer uniquement le trafic.

❌ Ignorer les comportements.

❌ Suivre trop de KPI.

❌ Ne jamais regarder les données.

❌ Modifier une interface sans mesurer l’impact.

❌ Confondre satisfaction et utilisation.

❌ Optimiser une métrique au détriment de l’expérience globale.


<a id="section-2"></a>
## Cas pratique
Imaginons un SaaS de facturation.

Les données montrent :

* beaucoup d’inscriptions ;
* peu de créations de factures.

Après observation :

Les utilisateurs ne trouvent pas le bouton :

Créer une facture.

Le problème n’est donc pas le marketing.

Le problème est l’UX.

Après amélioration :

* CTA plus visible ;
* onboarding simplifié ;
* première facture guidée.

Le taux d’activation augmente.

Construire une culture de la mesure

Une équipe produit performante suit toujours le même cycle.

Observer
↓
Mesurer
↓
Comprendre
↓
Améliorer
↓
Tester
↓
Mesurer à nouveau

Le design n’est jamais terminé.

Il évolue avec les utilisateurs.


<a id="section-3"></a>
## Checklist du chapitre
Avant de lancer une fonctionnalité :

* ☐ Les objectifs métier sont définis.
* ☐ Les KPI principaux sont identifiés.
* ☐ Le tunnel utilisateur est mesuré.
* ☐ Les abandons sont suivis.
* ☐ Le temps de tâche est observé.
* ☐ Les erreurs sont enregistrées.
* ☐ Les retours utilisateurs sont collectés.
* ☐ Les améliorations sont testées.
* ☐ Les décisions reposent sur des données.
* ☐ Les résultats sont suivis dans le temps.

Ce qu’il faut retenir

Une bonne expérience utilisateur n’est pas une opinion.

C’est un résultat observable.

Les métriques permettent de comprendre si les utilisateurs atteignent leurs objectifs, où ils rencontrent des difficultés et quelles améliorations auront le plus d’impact.

Les équipes les plus performantes combinent toujours observation, mesure et expérimentation pour faire évoluer leurs produits.
