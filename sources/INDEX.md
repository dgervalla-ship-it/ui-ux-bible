# Sources primaires — livres complets

Ces fichiers sont les **ouvrages d'origine** (OCR/EPUB→markdown). La synthèse dans `../references/` en distille l'essentiel ; viens ici quand tu as besoin du **détail exact, d'un exemple précis, d'une valeur concrète** (code couleur, nom de police, variante de composant) ou d'un sujet non couvert par la synthèse (surtout le marketing).

Lecture progressive : ces fichiers sont volumineux — lis-les par tranches (offset) autour de la partie utile, ne charge pas tout.

| Fichier | Quand le consulter |
|---|---|
| `sources/marketing-digital.md` | Marketing digital complet (23k lignes) : stratégie, SEO, SEA/publicité, emailing, réseaux sociaux, tunnel de conversion, acquisition, analytics. LA référence pour tout ce qui touche au marketing, pas seulement le design. Non couvert par la synthèse bible. Naviguer par 'Partie N / Page N'. |
| `sources/dont-make-me-think.md` | Steve Krug — utilisabilité web, principe 'ne me faites pas réfléchir', tests utilisateurs, navigation, conventions. Contient les vrais chapitres ('Chapter N. Titre'). Fondations UX. |
| `sources/design-of-everyday-things.md` | Don Norman — affordances, signifiants, mapping, feedback, modèles conceptuels, erreurs humaines. Le 'pourquoi' psychologique du design. Fondations. |
| `sources/refactoring-ui-v1.0.2.md` | Refactoring UI (OCR v1.0.2) — tactiques visuelles concrètes : hiérarchie, espacement, couleur, profondeur, images. Source des chapitres 4–8 de la synthèse. Naviguer par 'Page N'. |
| `sources/refactoring-ui-wathan-schoger.md` | Refactoring UI (autre extraction OCR) — même ouvrage, transcription différente. Croiser avec refactoring-ui-v1.0.2 si un passage est illisible. |
| `sources/font-recommendations.md` | Refactoring UI: Font Recommendations — polices recommandées avec appairages headline/subtitle/button, poids, licences (gratuite/payante) et sources. À consulter pour CHOISIR une police concrète (Proxima Nova, Inter, Roboto, Source Sans, Lato…). |
| `sources/component-gallery.md` | Refactoring UI: Component Gallery — inventaire visuel des variantes de composants (boutons, inputs, badges, breadcrumbs, pagination, nav, tables, alerts, pricing, heros, modals, footers, cards…). À consulter pour LISTER les variantes possibles d'un composant avant d'en concevoir un. |
| `sources/color-palettes.md` | Refactoring UI: Color Palettes — 13 palettes prêtes à l'emploi. Chaque palette = Primary, Neutrals/Grey, Supporting, avec les valeurs HSL ET hex exactes des 10 nuances. À consulter pour PRENDRE une palette réelle et ses codes couleur exacts. OCR : hsl et hex sont listés en alternance. |
